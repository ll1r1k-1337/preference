# Преферанс — журнал пульки (конвенция «Сочи», 3 игрока)

Приложение для ведения записи в преферанс: пулька, гора, висты, итоговый
пересчёт. Люди играют вживую, приложение заменяет бумажный лист записи.

Источник истины по правилам — [`docs/rules.md`](docs/rules.md).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 — журнал пульки
npm run build    # продакшен-сборка в dist/
npm run gate     # tsc --noEmit + тесты
```

## Архитектура

```
docs/rules.md          нормативная спецификация (SSOT)
   │
   ├── src/scoring     пуля, гора, висты, распасы, мизер, итог §9.9
   ├── src/game        партия: ротация сдающего, лист записи, сессия
   └── src/ui          ввод результатов и отрисовка; правил НЕТ
```

- **Все числа листа записи — из `scoring`.** UI ничего не пересчитывает сам.
- **`PlayerId`**: модуль расчёта использует строки (`'0'`, `'1'`, `'2'`).
